# 🛠️ Taller de Control de Versiones con Git & GitHub

Guía práctica y material de laboratorio sobre **Git** y flujos de trabajo colaborativos en **GitHub** para estudiantes de ingeniería de sistemas y desarrolladores de software.

---

## 📚 Contenido del Taller

1. **Fundamentos de Git:** Inicialización (`git init`), staging area (`git add`), commits atómicos y buenas prácticas de mensajes.
2. **Gestión de Ramas (Branching):** Creación, cambio de ramas (`git checkout` / `git switch`), fusiones (`git merge`) y resolución de conflictos.
3. **Flujos Remotos:** Configuración de remotos (`git remote`), sincronización (`git push`, `git fetch`, `git pull`).
4. **Colaboración en GitHub:** Pull requests, revisiones de código y etiquetas de versión (`git tag`).
